Практическая задача №1: Создание виртуального диска для проекта
Что нужно сделать:
Этап 1: Создание виртуального диска

Сначала создайте файл размером 500MB, который будет выступать в роли виртуального диска. Для этого используйте команду dd, которая умеет создавать файлы заданного размера:

dd if=/dev/zero of=~/virtual_disk.img bs=1M count=500

                  
Здесь if=/dev/zero означает источник нулевых байтов, of=~/virtual_disk.img - выходной файл в домашней директории, bs=1M - размер блока 1 мегабайт, count=500 - количество блоков.

Этап 2: Создание loop-устройства

Теперь нужно превратить этот файл в блочное устройство, с которым можно работать как с обычным диском. Для этого используется loop-устройство:

sudo losetup -f ~/virtual_disk.img --show

                  
Команда автоматически найдёт свободное loop-устройство (флаг -f) и выведет его имя (например, /dev/loop0). Запомните это имя - оно понадобится дальше.

Этап 3: Создание разделов

Используя fdisk, создайте на виртуальном диске два раздела:

Первый раздел размером 200MB для системных файлов
Второй раздел с оставшимся местом для пользовательских данных
При создании разделов используйте GPT таблицу. Помните, что размер можно указывать как +200M.

Этап 4: Обновление ядра о разделах

После создания разделов на loop-устройстве нужна специальная команда, чтобы система увидела новые разделы:

sudo partprobe /dev/loop0

                  
Или альтернативный способ:

sudo losetup -P /dev/loop0

                  
Теперь должны появиться устройства вида /dev/loop0p1 и /dev/loop0p2.

Этап 5: Создание файловых систем

Создайте разные файловые системы:

На первом разделе создайте ext4 с меткой "SYSTEM"
На втором разделе создайте xfs с меткой "USERDATA"
Этап 6: Монтирование и проверка

Создайте директории /mnt/project_system и /mnt/project_data, примонтируйте туда ваши разделы и создайте в каждом по тестовому файлу.

Что предоставить в качестве ответа:
Сделайте скриншот, на котором будут видны результаты следующих команд, выполненных последовательно:

lsblk | grep loop
df -h | grep project
ls -la /mnt/project_system/
ls -la /mnt/project_data/

                  
На скриншоте должны быть видны: структура разделов на loop-устройстве, примонтированные файловые системы с правильными размерами, и созданные вами тестовые файлы в обеих директориях.

Подсказка для очистки после выполнения:
После завершения задачи не забудьте размонтировать разделы и отключить loop-устройство:

sudo umount /mnt/project_system /mnt/project_data
sudo losetup -d /dev/loop0
rm ~/virtual_disk.img

Решение, команды пошагово:
dd if=/dev/zero of=virtual_disk.img bs=1M count=700 - создание образа размером 700МБ, выбрал 700МБ т.к. файловая система xfs требует минимум 300мб свободного места для ее создания
losetup -f virtual_disk.img --show - создание блочного устройства(loop) следующего по списку, в моем случае был /dev/loop15
Далее создание разделов через fdisk
fdisk /dev/loop15
В меню нажимем g для создания gpt таблицы разделов
Далее n для создание раздела, там же выбрием номер раздела, первый сектор(обычно просто жмем enter), последний сектор - тут указываем размер раздела, в нашем случае +200M
Аналогично для второго раздела, но там уже при указании размера просто жмем enter, чтобы он использовал все оставшееся свободное место
partprobe /dev/loop15 - нужно чтобы система увидела новые разделы
mkfs.ext4 -L "SYSTEM" /dev/loop15p1 - создаем файловую систему ext4 для первого раздела диска с лейблом "SYSTEM"
mkfs.xfs -L "USERDATA" /dev/loop15p2 - аналогично создаем файловую систему xfs для второго раздела с лейблом "USERDATA"
mkdir -p /mnt/project_system /mnt/project_data - создаем каталоги для монтирования разделов
mount /dev/loop15p1 /mnt/project_system - монтируем раздел, чтобы там возможно было создавать файлы
mount /dev/loop15p2 /mnt/project_data - монтируем раздел, чтобы там возможно было создавать файлы
По сути на этом все, можем проверить:
df -h | grep loop15 - тут можем увидеть куда примонтирован наш новый диск
blkid /dev/loop15p1 - детальная информация о разделе, с UUID и т.д.

В конце можем удалить этот диск
sudo umount /mnt/project_system /mnt/project_data
sudo losetup -d /dev/loop0
rm ~/virtual_disk.img
